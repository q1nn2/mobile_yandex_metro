## Описание

Цель работы - оценить стабильность и корректность мобильного приложения Яндекс Метро версии **3.6** после изменений, затронувших пользовательские сценарии построения маршрутов, работы карты, истории, тем, геолокации и системных взаимодействий.

Покрытие выполнено двумя наборами проверок:

- **Функциональное тестирование** (основные пользовательские сценарии);
- **Регрессионное тестирование** (критичные участки, которые не должны ухудшиться после релиза).
